# 過去問リンク内容照合ステータス (`src/data/links.json`)

過去問.com（kakomon.com）へのリンクを、公式PDF（`過去問/`フォルダ）の本文と1件ずつ突き合わせて確認済みか（＝全問内容照合済み）を科目・年度別にまとめたもの。

## 凡例

- **済み**: 該当年度・科目の全問題を1件ずつ本文取得してPDFと突き合わせ済み
- **未実施**: 問題数の整合性チェックや一部サンプル照合のみで、全問の内容照合はまだ行っていない
